# 대법원 전원합의체 판결·결정 정리 (2021. 1. ~ )

**2021. 1. 1. 이후 선고된 대법원 전원합의체 판결·결정을 분야별로 모아, 사실관계·쟁점·다수의견·종전 판례 변경·별개·반대의견을 판결문 원문 그대로 인용해 정리한 저장소입니다. 모든 인용은 법제처 공개 원문과 글자 단위로 대조했습니다.**

- 웹에서 보기: GitHub Pages 소개 페이지(분야·연도 필터, 검색)
- 정리 기준: [`CLAUDE.md`](CLAUDE.md)

## 정리 원칙

1. **원문과 요약을 섞지 않습니다.** 판결문 문장은 인용 블록으로 글자 그대로 옮기고 원문 위치(예: `— 이유 2.가.2)`)를 붙입니다. 정리자가 줄여 쓴 문장에는 `[요약]` 표시를 합니다.
2. **인용은 전부 기계로 대조합니다.** `tools/check_quotes.js`가 정리본의 모든 인용을 `raw/`의 원문과 대조하며, 하나라도 다르면 공개하지 않습니다.
3. **종전 판례 변경은 판결 이유 본문으로 판단합니다.** 법제처 데이터의 참조판례 "(변경)" 표시는 반대의견의 변경 주장에도 붙는 경우가 있어 그대로 쓰지 않습니다.
4. **평가·의의·전망은 쓰지 않습니다.**

## 대상과 범위

- 대상: 2021. 1. 1. ~ 2026. 10. 10. 선고 대법원 전원합의체 판결·결정
